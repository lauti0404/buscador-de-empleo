# Buscador de empleo

Programa para tu computadora. Busca avisos, los compara con tu CV y te deja el link para postularte, un CV en texto plano y una propuesta. No se postula solo. Tu CV y tus claves quedan en tu PC: no se suben a GitHub.

## Paso a paso

1. Entrá a https://github.com/lauti0404/buscador-de-empleo
2. Tocá el botón verde **Code** y después **Download ZIP**.
3. Descomprimí el ZIP. Tiene que quedar una carpeta con el archivo `instalar.bat` adentro.
4. Doble clic en `instalar.bat`.
5. Si Windows pregunta, aceptá. La primera vez puede instalar Python y tarda unos minutos.
6. Se abre el navegador solo en tu computadora y queda un acceso directo en el escritorio.
7. En **Archivo del CV**, subí tu CV en PDF, Word (DOCX) o TXT. El texto aparece en **Texto leído**. Si falta una palabra, corregila ahí.
8. Tocá **Buscar y filtrar**.
9. En cada aviso que te sirva, tocá **Armar CV y propuesta**. Ahí tenés el link para postularte, el CV de ese puesto y el texto de la propuesta. Podés copiarlos.
10. Para abrirlo otro día, usá el acceso directo **Buscador de empleo** del escritorio. No hace falta volver a instalar.

## Si el PDF es una foto

Algunos PDF no tienen texto, son una imagen. Para leerlos hace falta una clave gratis de Gemini:

1. Creala en https://aistudio.google.com/apikey
2. En el programa, abrí **Claves opcionales**, pegala en **Clave de Gemini** y tocá **Guardar claves**.
3. Volvé a subir el PDF.

Con esa clave también podés tocar **Generar CV para filtros ATS**. Redacta un CV nuevo en texto plano, sin columnas ni gráficos, usando solo lo que ya dice tu archivo. No inventa empleos, fechas ni herramientas.

## Claves para ver más avisos

Sin claves ya busca en varias bolsas de trabajo remoto. Estas son opcionales y cada persona usa las suyas:

- Jooble: https://jooble.org/api/about
- Adzuna: https://developer.adzuna.com/

Adzuna no publica avisos de Argentina. Si elegís otro país, la búsqueda pide puestos remote. Jooble sí trae avisos de Argentina, también presenciales. El casillero **Ocultar también los presenciales de Argentina** los saca.
