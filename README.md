# Buscador de empleo

Programa para tu computadora. Busca avisos públicos, los compara con el CV que pegues y te deja el link para postularte, un CV ordenado para ese puesto y una propuesta. No se postula solo.

## Instalar

1. Descomprimí esta carpeta.
2. Doble clic en `instalar.bat`.
3. Si Windows pregunta, aceptá. La primera vez puede instalar Python y tarda unos minutos.
4. Se abre el navegador solo en tu computadora. Pegá tu CV y buscá.

Para abrirlo después, usá el acceso directo del escritorio o `iniciar.bat`.

## Claves, si las querés

Sin claves ya busca en varias bolsas de trabajo remoto. Adzuna y Jooble suman más avisos, y cada persona carga las suyas en la pantalla. No vienen en este repositorio.

- Jooble: https://jooble.org/api/about
- Adzuna: https://developer.adzuna.com/

Adzuna no publica avisos de Argentina. Si elegís otro país, la búsqueda pide puestos remote. Jooble sí trae avisos de Argentina.

El CV y las claves quedan en la carpeta `datos` de esa computadora. Esa carpeta no se sube a GitHub.
